# Al-Ma'tsurat source and license notice (SIMPEG Mobile)

The offline Arabic recitations in this app are supplied by
`@guidelightid/almatsurat@0.2.0` (code © 2026 Guidelight and Khazanah
contributors; data © 2024 Aliif Arief). The package copies the four
Sugro/Kubro × Pagi/Petang collections from
`https://github.com/aliifam/almatsurat` at commit
`92edd45d7cfa0e5cd1528ccc16015dcb383419a9` under the MIT License.
The pinned source and per-file SHA-256 hashes are recorded in the package's
`dist/data/provenance.json` (exposed as `@guidelightid/almatsurat/provenance`).
The app imports that bundled package data directly for offline use; no
external website, network call, or separate copied JSON is required.

The package includes Indonesian translations of uncertain provenance. SIMPEG
Mobile intentionally displays only the Arabic recitation, the source item
titles, and the repetition counts; it does not display translations or Latin
transliteration. See the package's `NOTICE.md` for the original caveat.
